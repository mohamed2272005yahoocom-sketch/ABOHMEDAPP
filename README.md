# ABOHMEDAPP
An all-in-one desktop toolkit featuring a Universal Video Downloader, an Audio Extractor (MP3/MP4), and a smart Discord Video Compressor that automatically shrinks gaming clips to under 9MB. Built with drag-and-drop support. Note: The application interface is fully in Arabic.
